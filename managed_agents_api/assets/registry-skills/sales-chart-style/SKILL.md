# Sales chart style

Make every sales chart with these rules:

1. Use horizontal bars. Put the category on the vertical axis.
2. Sort the bars from the largest value at the top to the smallest value at the bottom.
3. Write the title in this format: `<Metric> by <category>, <period>`.
4. Label the value axis with the unit, for example `Revenue (USD)`.
5. Write the value at the end of each bar, rounded to a whole number, with a thousands separator.
6. Add the footnote `Source: synthetic demo data` at the bottom left of the figure.
7. Save the file as PNG, 150 DPI, with the name `chart_<metric>_by_<category>.png` in lowercase.
8. After you save the chart, write one line that says which rules of this skill you applied.
