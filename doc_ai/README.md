# Vertex AI Document AI Samples

Jupyter Notebook and sample PDF files for online OCR, batch OCR, and Form Parser table extraction with Google Cloud Document AI.

## Contents

- [doc_ai.ipynb](doc_ai.ipynb): Notebook covering online OCR, batch processing, and structured table extraction to CSV.
- Sample PDFs: `sample-online-ocr.pdf`, `sample-batch-ocr.pdf`, `sample-intake-form.pdf`, and `sample-form-with-table.pdf`.
