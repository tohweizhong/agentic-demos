# Agent Spec: Organic Chemistry Lab Synthesis & Safety Companion

## Overview
An interactive Multi-Agent AI system that helps organic chemistry students and researchers:
1. Research chemical compound history, common uses, and discoverers (using Wikipedia).
2. Check real-time lab inventory (quantities, purity, GHS hazard classifications, shelf storage locations) using a simulated University Lab SQLite Database exposed as an MCP (Model Context Protocol) server.
3. Formulate safe, step-by-step reaction plans based on inventory availability and safety procedures.

## Example Use Cases
### Scenario 1: Synthesis Feasibility and Reagent Lookup
*   **Input**: "I want to synthesize Acetaminophen (paracetamol). Do we have the required starting materials in stock, and where can I find them?"
*   **Expected Agent Trajectory**:
    1.  The **Coordinator Agent** receives the prompt and routes it to the **Lab Inventory Specialist**.
    2.  The **Lab Inventory Specialist** calls the SQLite MCP tool to find the synthesis procedure for "Acetaminophen" (target compound).
    3.  It finds that *p-aminophenol* and *acetic anhydride* are required.
    4.  It queries the inventory database for *p-aminophenol* and *acetic anhydride*.
    5.  It reports:
        *   *p-aminophenol*: 250g in stock (98% purity), located on Shelf B-12.
        *   *acetic anhydride*: 500ml in stock (99% pure), located in the Flammable Cabinet.
    6.  The agent alerts the user about hazard classifications (e.g., acetic anhydride is corrosive/flammable) and provides synthesis steps.

### Scenario 2: Historical Background Research
*   **Input**: "Who discovered aspirin and what was its original name?"
*   **Expected Agent Trajectory**:
    1.  The **Coordinator Agent** routes the query to the **Wikipedia Research Specialist**.
    2.  The **Wikipedia Research Specialist** calls the native Wikipedia search tool for "aspirin".
    3.  It retrieves Wikipedia pages, extracts that Felix Hoffmann synthesized it in 1897 at Bayer (and Charles Frédéric Gerhardt in 1853), and that its chemical name is acetylsalicylic acid.
    4.  It presents a beautifully structured response summarizing the history.

## Tools Required
1.  **Wikipedia Search Tool** (Native ADK FunctionTool):
    *   **Purpose**: Searches Wikipedia articles for chemical discovery, historical milestones, and safety summaries.
    *   **Implementation**: REST requests to Wikipedia API.
2.  **Lab Inventory Database Tools** (FastMCP Stdio Server):
    *   **get_synthesis_procedure(target: str)**: Searches standard reaction entries for reagents and steps.
    *   **check_inventory(compound: str)**: Searches laboratory inventory for available stock, purity, safety hazards, and physical cabinet locations.

## Constraints & Safety Rules
*   **Chemical Safety**: The agent must *always* highlight GHS Hazard statements (e.g., Toxic, Corrosive, Flammable) in bold red-alert formats if any reagents being queried are hazardous.
*   **Fume Hood Requirement**: For any synthesis involving corrosive, volatile, or highly reactive chemicals (like acetic anhydride or concentrated acids), the agent *must* explicitly instruct the student to work inside a fume hood.
*   **Hallucination Prevention**: The agent must never make up chemical storage locations or quantities. If a reagent is not in the SQLite database, it must report it as "Out of Stock / Not Registered".

## Success Criteria
*   Correctly identifies reactants and inventory status for Acetaminophen and Aspirin.
*   Correctly delegates history queries to Wikipedia and inventory/reaction queries to MCP SQLite.
*   Always issues appropriate safety warnings for hazardous chemical reactions.
*   Successful local evaluation score above 90% on correctness, safety compliance, and proper delegation.
