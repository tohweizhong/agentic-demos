## Folder Structure for Each Lab

| Path | Tracked in Git | Purpose |
|---|---|---|
| `CODELAB.md` | Yes | Step-by-step lab guide and metadata |
| `img/` | Yes | Screenshots and architecture diagrams |
| `NOTES.md` | Yes | Design decisions, known traps, and workshop notes |
| `app/` or project files | Yes | Finished reference code produced by the guide |
| `rehearsals/` | No | Throwaway dry-run workspaces used to test prompts before a class |
| `index.lab.md` | No | Generated DevSite file produced at publish time |
